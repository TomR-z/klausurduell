# Klausurduell

Lern-App für das Bauingenieurstudium an der RWTH: Merk- und Vorgehensfragen mit Lernstufen, Tagesziel und Serie.

- App öffnen: `https://<benutzername>.github.io/klausurduell/`
- iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“
- Der Lernstand liegt nur auf dem Gerät. Backup unter „Lernstand → Daten sichern“.

Version 2.5.4 · Fragen in `fragen.js`, App in `index.html`, 3D-Grafik der Stadt mit three.js (MIT-Lizenz) in `three.min.js`.


## Stadt 3.0 (Vorschau-Zweig)
3D-Modelle der Stadt: Kenney City Kits (Suburban, Commercial, Industrial, Roads), Car Kit und Train Kit – CC0, kenney.nl. Gepackt in `stadt.glb` (Meshopt), geladen mit dem GLTFLoader von three.js (MIT) in `gltf-umd.js`.
